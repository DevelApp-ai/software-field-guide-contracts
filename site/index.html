Estate and Seam Contract Validator

Companion to The Software Field Guide, chapter “Segmenting the Estate”. Contracts are checked in your browser by the same Rego policies the CLI runs — nothing is uploaded.

Paste an enclave contract as JSON — four answers plus a review date: enclave, owner, trustedIdentityPlanes, borderInventory, blastRadius, reviewedOn. Convert YAML with yq -o=json '.' enclave.yaml.

Paste a seam contract as JSON — six answers plus a rehearsal date: seam, enclave, entry, decision, monitoring, blastRadius, killPath, lastRehearsed, reviewDate.

Paste the whole estate as JSON: {"enclaves": [...], "seams": [...]}. This checks names are unique, every seam belongs to an enclave, and every border inventory entry has a seam contract behind it.

The playground loads the validator from wasm/ next to this page. To run it locally from a checkout: make site and serve the site-build/ folder (wasm needs http, not file://). CLI equivalent: make check-enclave FILE=....
